# Changelog

All notable distribution and public-interface changes are recorded here.

## 0.1.0a7 — publication-closure candidate

- add the unified, read-only `cmba-agent` discovery and dispatch interface;
- bundle exact I1, J1, and K1 request schemas for installed discovery;
- add ABI compatibility and agent framing documentation;
- add public onboarding, contributor, security, conduct, and publication files;
- add separated core-only and optional-native contributor test lanes and GitHub Actions CI;
- preserve the established I1/J1/K1 protocol-specific interfaces and excluded
  effect boundary.

- close exact Windows qualification, fresh-install, source reproducibility, and
  evidence-envelope gaps;
- retain the I1 semantic contract and bounded J1/K1 application surfaces.

Earlier batch history is retained under `history/` and the batch dossiers.
