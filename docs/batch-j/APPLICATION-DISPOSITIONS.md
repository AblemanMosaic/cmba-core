# Application accounting — J1

The inherited I1 catalogue remains byte-identical as a historical/core reference.
`catalogue/APPLICATIONS-J1.json` and installed `data/j1-catalogue.json` supply current cards,
preserve every original source record, and add **engineering-authored** mappings separately.
Every recovered domain row retains its original source name, dimensions, use case and line anchor.

The catalogue has 71 entries, consisting of 52 actual historical domain rows and 19 application
family mappings. It additionally contains 52 explicit record templates. Templates are NOT
working domain engines. The source heading's “51 applications/10 sectors” differs from its
52 actual table rows/eight sections; this discrepancy remains recorded, not silently corrected.
