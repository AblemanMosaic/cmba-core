# Batch J acceptance and evidence obligations

J is the application-family batch of I–L. It adds bounded realizations rather than completing
the operational versions of all historical application concepts. Every result below is subject
to exact frozen-source test and replay receipts. A list of obligations is not itself a pass.

| Obligation | Implementation and principal negative evidence |
|---|---|
| I1/DKN preservation | Exact inherited runtime/data/contracts/corpus and native archive/wheel comparison |
| Typed materialized components | Projection mismatch, wrong profile, unknown critical field, missing record |
| Signature construction | RFC vector; inadmissible keys; domain/body substitution; scalar encoding |
| Endorsement policy | No circular hash; exact policy/requirement/action; same-key and duplicate evidence |
| CHC | Wrong input/output/toolchain; cycles/duplicate producer/missing/unused node |
| GenDev | Fabricated quote; complete-capture overclaim; attributed interpretation remains unproved |
| KASD | Missing one joint approval; wrong scope; signed denial; overlapping incompatible constraints |
| Consent | Expiry; changed actor/resource/context/condition; withdrawal; override; subdelegation refusal |
| Disclosure | Wrong salt/value/path/index/root/count; required-label omission; no private fixture in selected view |
| Observation | Wrong bytes/reference; unauthorized testimony; no physical-reality relabeling |
| Coordination | Duplicate/missing participant; changed terms; wrong phase/predecessor; no consensus claim |
| Reconciliation | Null/absence/type distinction; conflicts retained; no silently invented winner |
| Execution correspondence | Different artifact/config/target/operation; stale/unrecognized observations |
| Claim trace | Missing citation; existing citation does not promote claim truth |
| Admissibility | Recompute children, exact subject/time, missing approval propagated; no submitted PASS shortcut |
| DKN subsystems | Actual native archive/namespace/lineage/LC/SAM/DS routine, snapshot reads and native refusals |
| Interfaces and limits | Closed read-only ABI; explicit reader context; canonical types; finite records/proofs |
| Session-to-release example | Session/transform/actual DKN artifact/approvals/consent/disclosure with later expiry |
| Replacement conformance | Frozen exact full result/refusal envelopes; bool/int and null differences refuse |
| Model binding | Source/reference/symbol/current-execution traceability, not equivalence proof |

The J1 contract enumerates finite guarantees and their exclusions, separately from I1. Its
realization binding names exact implementation/test references. The program ledger records J
completion scope and K/L not-yet-completed status. Historic DKN fifty-obligation states are not
changed by this adapter batch; its unexecuted legacy or deployment gates remain unexecuted.

Evidence legs are distinct: cumulative CMBA suite, frozen DKN v0.2 suite, executable workflows,
conformance, model checks, optional native crypto comparison, installed-wheel checks, inherited
native GUI smoke, closed-package verification, and clean-extraction replay. Conformance cases
included in pytest are not counted twice. Missing optional runtime dependencies block their
mandatory test leg; they are not replaced with mocks or relabeled as successful execution.
