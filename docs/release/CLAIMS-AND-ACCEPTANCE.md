## Inherited acceptance

I1's semantic commitment retains exact bytes. J1/K1 commitments are renewed because their
contracts bind renewed realization-dependent corpora. Their 18 + 28 + 26 obligations remain
mechanically traceable to reference files, implementation files and executed test names; J-01
and K-01 are successor-transition clauses rather than claims of exact predecessor-byte retention.
This is not a whole-program refinement proof. DKN's original 50-obligation ledger remains
35 scoped passes and fifteen limited obligations; CMBA does not promote them by wrapping it.

The catalogue's 52 historical domain records plus 19 family mappings remain an inventory.
Reference-only records cannot turn into medical, election, legal or operational-control
engines through installation. No operational weapons/nuclear control is part of this scope.

## L completion gates

L qualifies the existing feature surface, not new applications. Required local legs:
source admission and predecessor preservation; complete CMBA test identity coverage; six
examples; three frozen conformance corpora; the separate-language small core; actual native
GUI interactions; foreign cryptographic-library comparisons; model pin/reference/test
checks; native DKN replay; core-only and optional installed environments; byte-identical
source/wheel rebuild; and exact external release-envelope closure.

Only executed legs receive PASS in the final receipt. Conformance and GUI tests may appear
both as pytest items and explicit tools; their totals are not summed as unique cases.
Separately reported DKN tests are not new CMBA tests. Frozen-tree reproducibility is not
identical regeneration of timestamps/timings/temporary paths in fresh evidence logs.

## Unclosed external gates

macOS runs, independent security review, a full alternative-language realization, production
key/clock/floor custody, domain approvals and live deployment validation remain unestablished.
The a6 delivery may include real-junction refusal, genuine BLAKE3 legacy replay, exact native
platform coverage, and fresh optional-dependency resolution as same-author local evidence, not
independent certification. Those claims apply only when the exact receipts are members of the
verified outer release envelope; the source ZIP and replay scripts are not those results. No whole-program semantic
proof, live P2P/federation/consensus system, automatic code generator or publication occurs.

The a7 successor is cleared for publication only as an alpha research preview. Same-author
engineering results are suitable for bounded integration experiments and independently selected
review, not an unattended trust root or production certification.

## Post-L process qualification correction

The local engineering runners are not a native P/PPI host. Native registration, admission,
work selection and mediation remain NOT_ESTABLISHED. See [P/PPI audit](../audit-r001/PIPPI-AUDIT.md).
The source/evidence closure repairs in [the review findings](../audit-r001/FINDINGS.md)
supersede broad implications that every stage metadata field or native source addition was
previously rejected. Prior L test results remain valid measured runs, not proofs of those
stronger invariants. Audit r001 introduced no runtime/application protocol changes. The
0.1.0a5 successor changed core junction refusal and WB-K1's Windows create-only installation
realization. The 0.1.0a6 successor adds no runtime feature: it repairs qualification admission,
coverage, evidence binding, portable packaging, and the bound platform contract. I1/J1 remain
exact; K1 preserves its operational guarantees under a renewed commitment.
