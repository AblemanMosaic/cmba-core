# Adoption, compatibility and rollback

The qualification-and-contract successor changes the distribution to 0.1.0a6, not the
I1/AP-J1/SE-J1/SD-J1/WB-K1 protocol versions.
No namespace, vault, workspace or reader pin is migrated on installation. No updater is
installed. Adopt into a separate environment and select it explicitly.

The I1 semantic contract and small-core corpus remain byte-identical. The a5 local-file reader
and WB-K1 effects repairs remain the runtime realization; a6 changes qualification tools, tests,
documentation, and package metadata rather than adding runtime features. The K1 commitment is
renewed to bind its normative platform amendment. Historical
receipts remain replayable with the exact historical runtime, context and material. The frozen
DKN artifact keeps its independent identity.

The I1 model body, commitment and corpus remain byte-identical. J1/K1 model bodies, commitments
and corpora are deliberate successors, and all realization bindings change.
Historical source inventories and receipts are historical, not current-source certifications.
The current source inventory and external release envelope replace no prior evidence.

The source-archive verification tool deliberately rejects self-consistent but nonportable,
nonregular or type-confused inventories previously accepted by that tool. Valid emitted I/J/K
source archives still satisfy its profile. These stricter release checks do not alter runtime
artifact/root/signature meaning.

Keep the previous wheel and exact source if rollback may be needed. Restoring older software
does not restore withdrawn consent, recover lost signing keys, or make an old evidence view
current. Workspace import does not restore trust selection. Re-establish reader policy and
external rollback floors through the accepted operator path. Restoring a whole local database
can restore its old internal floor; a genuinely separately protected floor is deployment work.

No production data is modified by this qualification. Explicit test exports use temporary
paths. User-side installs and target-platform commands in the guides have not been performed
on the user's computer.
