release/replay receipts and raw evidence; original I–L program and frozen DKN Batch H source;
current normative specifications and all three model/realization maps. The transcript's

pytest official documentation, "Writing plugins" and "How to install and use plugins".
https://docs.pytest.org/en/stable/how-to/writing_plugins.html
https://docs.pytest.org/en/stable/how-to/plugins.html

and explicitly configured plugins require their own handling. The contamination finding
was reproduced locally against the actual pinned source, not inferred from the docs alone.

security, clinical, election, performance, commercial or patent claims.
