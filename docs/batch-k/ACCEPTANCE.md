# Batch K acceptance map

The I–L program remains the scope source. Historical aspirations do not become passes merely
because a catalogue entry exists. The base and J1 contracts remain frozen; K adds its own
bounded obligations rather than reinterpreting those contracts.

| Program requirement | Implemented surface | Evidence / boundary |
|---|---|---|
| Integrated native application use | Ten pages; all thirteen J1 examples use actual evaluators | smoke_workbench_k.py; not a domain engine or production key ceremony |
| Author/read separation | Explicit JSON draft authoring and reader context selection | test_authoring_preserves_no_stale_approvals; no signing or file writes |
| Local relationship navigation | Reverified finite local graph, filters, exact comparison, explicit follow | test_navigation_resolution_scope_and_truncation; no network/global coverage |
| Jurisdiction and consent visibility | Per-predicate matrix plus raw scoped detail | Actual GUI profile loop and unchanged J1 negative tests |
| Receipt history and replay | Packets, replay marks and compared input hashes | test_imported_claimed_receipt_needs_replay; both receipts recomputed |
| Selective views | Verify before selecting; export only the retained public view | test_disclosure_export_contains_only_selected_openings; no encryption |
| Explicit local save/import/export | Host plan, confirmation, expiry, input/directory/target checks | test_prepare_cancel_approve_commit_exact_and_no_overwrite; operator-owned local FS |
| Replacement and cancellation | Generation-bound results and one read-only worker | test_task_source_change_cancellation_and_rehashed_forgery; not thread termination |
| Profile-design exploration | Finite enumerated axes, supported mechanisms and unmet obligations | test_explorer_explicit_unsupported_combinations; no inferred security score |
| Realization qualification view | Exact declaration comparison and installed model/corpus references | test_qualification_never_promotes_declarations; no new replacement execution |
| DKN/CCP/UCM/P/PPI/Courthouse handoffs | Reference-only locally exportable envelopes | test_handoff_references_only_no_submission; external operational integration unestablished |
| Python/CLI/JSON and native UI | Headless Workspace, read-only cmba-wb, explicit cmba-export, Tk | CLI parity, TTY refusal and actual native GUI tests |
| Workspace persistence | Explicit finite canonical snapshots, no trust restoration | test_workspace_roundtrip_does_not_restore_trust; no autosave |
| Preserved identity/model semantics | All prior runtime files and frozen semantic/corpus bytes | test_core_evaluator_identity_is_unchanged_from_frozen_j and preservation manifest |

Every original Batch K item has a bounded realization or an explicit conditional exclusion:
there is no selected external compiler adapter requiring a process runner, because the supported
transforms already run in the fixed pure J1 handlers. Therefore K introduces no arbitrary
executable launcher. Target-machine testing, real external integration, independent review and
production authority/custody are not inferred from local code coverage.

Exact measured denominators are recorded in the release receipts. Conformance cases appear in
pytest and separately run through the process oracle; those are repeatability legs, not extra
unique tests. GUI checks are recorded separately and also exercised by a required pytest leg.
The inherited DKN total is never mixed into the new CMBA count.
