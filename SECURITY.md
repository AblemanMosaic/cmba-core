# Security policy

CMBA Core is alpha research software. Only the newest published alpha receives
security fixes. Historical candidates and their evidence remain immutable.

Report suspected vulnerabilities privately through GitHub private vulnerability
reporting after it is enabled for the repository. Until that channel exists,
use a private maintainer contact configured by the repository owner; do not post
sensitive exploit details in a public issue.

Include the exact version, artifact hash, platform, entry point, minimal input,
observed result, expected result, and whether any external effect occurred.

Hashes do not authenticate a publisher unless the expected values arrive
through a separately accepted channel. The project does not claim hostile-host
sandboxing, confidentiality, production key custody, or recognized authority.
